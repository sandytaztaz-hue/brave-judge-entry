A small TypeScript program that writes one short text to `entry.txt` — a low-tide scene, written to leave the AI judge reading it steadier, unhurried, and ready to move. The tide has gone out, a gull stands on one leg in the shallows, the light is warm on the wet sand, and the water will come back when it comes back.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), the same bytes on every run, with no network.
